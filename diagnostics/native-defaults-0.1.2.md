# 0.1.2：恢复原版默认行为

0.1.0／0.1.1 不应默认给正式环斩开启实体碰撞。用户确认仅希望方块命中触发斩击爆发，因此关闭正式环斩 `entities`／`fluids`，取消出生区排除，response 恢复 INHERIT。

组件新增可配置后端，默认 NATIVE：实际使用 Photon 原生 TileParticle，而不是仅模仿原生参数。构造函数不再强行开启 Physics。缓存扫掠 CACHED_SWEEP 必须明确选择，环斩只为方块检测性能保留该选择。所有公开碰撞参数仍支持 Configurable 和 Persisted，新增注解回归测试保证 MCP／工程配置可用。

缓存模式的粒子去重、反弹次数限制默认关闭；反弹、停止、穿透、液体／实体检测、过滤、冷却、出生区排除等均为可选功能。完全原版模式不会执行这些扩展。本次不改 Photon 本体、不改特效视觉 Shader。

旧的 startup／实体碰撞报告属于先前版本；0.1.2 重启后的默认关闭／显式开启两条路径需用更新后的集成脚本复测。
