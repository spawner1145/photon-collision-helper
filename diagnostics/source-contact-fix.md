# 环斩释放点延迟气环

0.1.0 已复现：在空虚拟世界、环斩根节点 `(0.5, 2, 0.5)`，源点附近放置生物 `(0.7469, 2.435, 0.9059)`，初始出生环的宽检测盒与该实体重叠。记录到 tick 0 的 ENTITY 接触，接触点约 `(0.9969, 3.6027, 1.1559)`，第 2 个模拟 tick 创建等待中的碰撞子特效，第 52 tick 在此生成局部气环。

这是实接触被误当作目标的问题，不是最后阶段额外配置了中心爆炸。`ignoreOwner` 只能从 EntityEffectExecutor 或显式实体 ID 识别施放者，`/photon fx ... block` 没有这一上下文。

0.1.1 修复：新增可持久化 `sourceEntityExclusionRadius`，环斩设为 1.25 世界格。第一次模拟时，在运行时根节点记录与该小球相交的已有实体 ID，本次释放排除这些实体。名单不随之后根节点或实体移动重新扩大，重播会清空。方块不受影响，出生区外的玩家和生物也没有被整体禁用。

单元测试覆盖球与实体 AABB 的相交、坐标平移、水平／垂直远离、禁用及无效半径。新游戏内回归脚本 `integration/verify_source_contacts.mjs` 覆盖旧行为复现、源点无假爆炸、源点实体离开后仍排除、远目标正常爆炸、近目标正常爆炸和源点真实方块命中；需新版组件正式加载后运行。
